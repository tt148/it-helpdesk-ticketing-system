# Contributing (lite)

1. Fork the repository and create a focused branch (`feat/ticket-export`).
2. Use conventional commit messages (`feat:`, `fix:`, `test:`, `docs:`, `chore:`).
3. Add or update tests for behavior changes and run `pytest`, `python manage.py check`, and `ruff check .`.
4. Never commit `.env`, credentials, personal data, or production database dumps.
5. Open a pull request with the motivation, implementation notes, and test evidence.
